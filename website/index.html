使用前，你可能想知道。

会改变其他 Mac 应用的快捷键吗？

不会。Windows 与 macOS 预设只在 Winway 内生效。在设置中可以切换预设或单独修改某个按键，两套配置独立保存。Ctrl 指键盘上的 Control 键；部分键盘需要 Fn+F2。

搜索为什么可能暂时没有结果？

首次搜索需要建立索引，后续文件变化也可能有更新延迟。受保护目录需要相应的完全磁盘访问权限，内容索引存在文件类型和大小限制；结果不完整不代表文件不存在。详细步骤见 搜索与权限说明。

能和 Finder 互相剪切、粘贴文件吗？

当前文件剪贴板在 Winway 内共享，支持跨标签复制、剪切和粘贴，尚未与 Finder 的文件剪贴板互通。也不支持同名覆盖和目录合并；发生冲突时可以跳过、保留两者或取消。

支持哪些 Mac？

提供 Apple Silicon 和 Intel 两种安装包，最低编译目标为 macOS 13。项目仍在持续完善，不同系统版本的兼容性需要更多实机反馈。遇到问题可在 GitHub Issues 提供系统版本、芯片类型和复现步骤。
