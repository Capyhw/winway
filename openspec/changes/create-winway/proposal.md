# Proposal

## Why

Winway 面向在 macOS 上希望沿用 Windows 11 文件管理习惯的用户，提供真实的本地文件管理能力和熟悉的多标签界面。用户已确定产品名、独立新项目、Figma 视觉来源，以及设置中切换键盘习惯和自定义按键的需求。

## What Changes

- 在当前 `winway/` 项目根目录建设独立 macOS 桌面应用，使用本地 Figma MCP 读取的文件 `wGLenm7aPmWyd9rDVtjfkm`、节点 `2:38` 作为视觉基准。
- 提供 macOS 原生窗口控制与 Win11 风格的顶部标签、导航栏、命令栏、目录侧栏、文件列表、详情面板和状态栏。
- 提供真实目录浏览、独立标签历史、路径输入、排序、当前目录名称过滤、多选和本地文件打开。
- 提供新建文件夹、复制、剪切后粘贴、重命名、移到废纸篓，以及冲突、部分失败和操作进度反馈。
- 设置中提供 Windows / macOS 键盘预设、自定义绑定、冲突提示、恢复默认和持久化；编辑文本时保持文本快捷键语义。
- 适配 macOS 的真实目录、卷和系统权限；以真实文件属性和支持格式的预览替代示意数据。

首版建议默认 Windows 键盘预设、中文浅色界面、单窗口多标签、本地文件优先。这些属于本提案的可评审默认值，并非用户逐项指定。首版不包含云盘账号接入、网络共享发现、全盘索引、替换 Finder、永久删除、通用撤销或自动更新。

## Capabilities

### New Capabilities

- `winway-workspace`: 原生桌面窗口、Figma 界面、标签与导航状态。
- `winway-file-browsing`: 真实目录和卷、排序过滤选择、打开及属性预览。
- `winway-file-operations`: 文件操作、剪切状态、同名处理、进度与失败恢复。
- `winway-keyboard-settings`: 预设切换、自定义快捷键、上下文分发和配置保存。

### Modified Capabilities

无。当前 OpenSpec 根目录没有现有能力规格。

## Impact

- 项目根目录为 `winway/`，OpenSpec 已迁入该目录；实现代码将直接置于此根目录，不再嵌套 `winway/winway/`。本轮仅创建目录、迁入 OpenSpec 并编写规划文件，不改动同级已有应用。
- 采用用户已确认的 Swift 原生方案：AppKit 承担主窗口、文件列表与事件处理，SwiftUI 承担设置和部分详情界面，Swift 文件服务处理磁盘任务；使用 Swift Package Manager 构建和测试，并打包为本地 `.app`。
- 文件操作涉及用户真实文件、系统废纸篓和系统默认打开方式，必须以临时测试目录完成实机验收。
- 首版交付目标是当前 Mac 可运行的开发版本及本机构建的 `.app`；签名、公证、公开分发和其他平台不在本次交付内。
