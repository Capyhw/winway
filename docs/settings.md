# 设置与首次引导

设置窗口左侧分为「快捷键」「权限」「关于」。快捷键沿用独立预设、录制、冲突校验和保存机制；菜单「关于 Winway」打开同一设置窗口的关于页。

首次权限引导可以选择稍后设置，不阻止文件浏览。返回软件后重新检测，权限确认后才自动启动索引。权限开关是系统授权状态的入口，实际更改由 macOS 完成；搜索服务有独立的状态反馈与完整重建入口。检测与重建细节见 [搜索说明](search.md)。

关于页从应用包读取版本号与构建号。点击「检查更新」读取 `https://api.github.com/repos/Capyhw/winway/releases/latest`，按数值比较三段版本，拒绝草稿、预发布和非官方仓库下载页。请求有 20 秒超时，区分无发布版本、限流、网络失败与无更新。发现新版本后打开 GitHub 发布页，由用户选择安装包；不会自动安装、替换或重启应用。

验证：`scripts/test-settings.sh` 用注入的权限及索引服务验证未授权不索引、授权后启动、撤销权限、辅助进程权限不一致、重建失败与重试，并验证更新可用/无更新/网络错误。设置 `WINWAY_SETTINGS_SCREENSHOTS` 可输出四个视图的渲染图。该测试不修改本机系统权限；真实授权切换需在目标 Mac 的系统设置中确认。
